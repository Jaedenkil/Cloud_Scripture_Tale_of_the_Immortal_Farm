## 说明
- 本文同时包含 16:9 与 5:3 两组逻辑分辨率，避免比例混淆。
- 推荐优先选择能被主流显示器整除的放大倍数，保证像素清晰无模糊。
- 逻辑分辨率越低，放大倍数越高，适合像素风格。
- 也可根据实际窗口自适应选择最接近的整数倍缩放。
- 术语约定：
	- `4K` 默认指 3840×2160（UHD）
	- 2560×1440 建议标注为 `QHD` 或 `1440p`，避免和 2K 混用
- 如需其他分辨率或特殊比例，可补充说明。
