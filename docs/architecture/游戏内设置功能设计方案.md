# 游戏内设置功能设计方案

## 1. 目标与范围

本文定义游戏内“设置”系统的分类、选项与功能描述，作为后续配置化（YAML）与运行时渲染实现的需求基线。

目标：

1. 为玩家提供完整、可理解、可回滚的设置能力。
2. 保证低门槛（新手可用）与高自由度（进阶可调）并存。
3. 支持后续配置驱动扩展（新增选项不改核心流程）。

范围：

1. 本文仅定义功能设计与信息架构。
2. 不包含具体代码实现与具体 YAML 字段约束实现细节。

## 2. 参考案例

参考：Stardew Valley 的设置菜单（显示、音频、输入、辅助）
实现方式：分区标签 + 简洁选项 + 立即生效项与需重启项分离提示
适用性：适用
本项目调整：增加修仙/农场特有辅助项（炼丹确认、离线收益、农务提醒）

参考：Hades 的可访问性与战斗辅助设置
实现方式：将核心辅助（瞄准、受击反馈、文本可读性）独立成高频入口
适用性：部分适用
本项目调整：将“无障碍”与“玩法辅助”分离，避免战斗辅助与视听辅助混杂

## 3. 信息架构总览

建议设置主页采用一级分类 Tab：

1. 显示与性能
2. 音频
3. 控制与输入
4. 玩法
5. 界面与信息显示
6. 无障碍
7. 联机与社交
8. 存档与数据

交互约束建议：

1. 即时生效项：调整后立刻应用（音量、UI 缩放等）。
2. 需重启项：修改后显示“重启后生效”标记（显示模式、部分渲染参数）。
3. 危险项：清晰二次确认（恢复默认、清理缓存、覆盖云存档）。
4. 提供“恢复本页默认”与“恢复全部默认”两级回退。

## 4. 分类与详细选项

### 4.1 显示与性能

| 选项         | 可选值/范围          | 默认值     | 功能描述                               |
| ------------ | -------------------- | ---------- | -------------------------------------- |
| 显示模式     | 全屏/无边框/窗口     | 无边框     | 控制窗口呈现方式，平衡沉浸与切屏效率。 |
| 分辨率       | 跟随显示器或手动选择 | 跟随显示器 | 控制渲染清晰度与性能占用。             |
| 帧率上限     | 30/60/90/120/无限制  | 60         | 限制帧率，平衡流畅度、功耗与发热。     |
| 垂直同步     | 开/关                | 开         | 减少画面撕裂，可能增加少量输入延迟。   |
| 画质预设     | 低/中/高/极致/自定义 | 高         | 一键调整阴影、特效、后处理等综合参数。 |
| 渲染比例     | 70%-150%             | 100%       | 在低配设备提帧或高配设备提高清晰度。   |
| 屏幕震动强度 | 0%-100%              | 70%        | 调整受击与技能冲击反馈，缓解晕动不适。 |

### 4.2 音频

| 选项     | 可选值/范围    | 默认值 | 功能描述                          |
| -------- | -------------- | ------ | --------------------------------- |
| 主音量   | 0-100          | 80     | 控制所有声音总输出。              |
| 背景音乐 | 0-100          | 70     | 控制 BGM 音量。                   |
| 环境音   | 0-100          | 70     | 控制天气、场景环境等氛围音。      |
| 音效音量 | 0-100          | 80     | 控制战斗、采集、UI 点击等效果音。 |
| 语音音量 | 0-100          | 80     | 控制角色语音与剧情语音。          |
| 动态范围 | 夜间/标准/影院 | 标准   | 适配耳机、外放与夜间低噪场景。    |
| 后台静音 | 开/关          | 开     | 切出游戏后自动静音。              |

### 4.3 控制与输入

| 选项          | 可选值/范围          | 默认值   | 功能描述                           |
| ------------- | -------------------- | -------- | ---------------------------------- |
| 输入设备优先  | 键鼠/手柄/自动       | 自动     | 决定提示图标与输入焦点切换策略。   |
| 鼠标灵敏度    | 1-20                 | 10       | 调整鼠标移动与视角控制速度。       |
| 手柄震动      | 开/关 + 强度 0-100   | 开/60    | 调整手柄反馈强度。                 |
| 摇杆死区      | 0%-30%               | 10%      | 缓解摇杆漂移并提升微调稳定性。     |
| 键位绑定      | 全动作可改           | 默认布局 | 支持冲突检测、恢复默认、设备分组。 |
| 长按/切换行为 | 冲刺/潜行/采集可切换 | 长按     | 减少高频按压疲劳，提升舒适度。     |

### 4.4 玩法

| 选项         | 可选值/范围                | 默认值  | 功能描述                             |
| ------------ | -------------------------- | ------- | ------------------------------------ |
| 难度模式     | 休闲/标准/硬核             | 标准    | 影响敌人强度、资源产出与失败惩罚。   |
| 自动存档频率 | 5/10/15/30 分钟            | 10 分钟 | 降低异常退出导致的进度损失。         |
| 新手引导     | 完整/精简/关闭             | 完整    | 控制教程密度与提示频率。             |
| 战斗辅助     | 自动锁定/受击慢放/技能提示 | 开      | 降低战斗上手门槛。                   |
| 农务辅助     | 播种提示/浇水提醒/收获高亮 | 开      | 降低重复劳动，提升经营节奏。         |
| 炼丹炼器确认 | 稀有材料二次确认 开/关     | 开      | 防止误耗高价值材料。                 |
| 离线收益     | 开/关                      | 开      | 允许离线期间作物成长与基础产出累计。 |

| 消息过滤     | 系统/交易/队伍/世界频道 | 标准过滤 | 降低聊天信息干扰。         |

## 5. 状态与交互提示规范（建议）

1. 选项状态统一分为：即时生效、需确认、需重启。
2. 对“影响存档、影响联机、影响性能”的选项显示风险说明。
3. 对较复杂选项提供简短说明文案（不超过 28 字）。
4. 所有滑杆支持键盘左右键微调与手柄精细调节。

## 6. 后续落地建议

1. 在 `scenes/panel` 增加设置主页面与分类子页面配置。
2. 在 `scenes/ui-flow.yaml` 中接入“主菜单 -> 设置 -> 返回”流程链路。
3. 在运行时将设置项映射到统一配置存储（本地 + 可选云同步）。
4. 分阶段上线：先基础设置（显示/音频/控制），再玩法与无障碍。

## 7. 验收清单

1. 分类完整可达，所有选项可进入并可退出。
2. 即时生效项可在当前界面实时感知。
3. 需确认与需重启项具备明确提示与二次确认。
4. 恢复默认行为正确，不误伤其他分类配置。
5. 配置持久化正确，重启后状态一致。

## 8. 设置页面 UI 设计描述

### 8.1 设计目标

1. 让玩家在 3 步内完成常用设置调整（进入分类 -> 修改 -> 应用/即时生效）。
2. 保证“好找、好懂、可回退”：分类清晰、文案简短、默认值与重置路径明确。
3. 同时支持键鼠与手柄操作，满足修仙农场玩法下高频调节场景（音量、农务辅助、战斗辅助）。

### 8.2 页面结构（信息层级）

1. 顶部栏：标题“设置”、返回按钮、当前分类名、搜索入口（可选）。
2. 左侧分类导航（一级 Tab，纵向）：
   - 显示与性能
   - 音频
   - 控制与输入
   - 玩法
   - 界面与信息显示
   - 无障碍
   - 联机与社交
   - 存档与数据
3. 右侧内容区（二级设置项列表）：
   - 每项由「名称 + 简述 + 控件 + 状态标签」组成。
4. 底部操作栏（常驻）：
   - 恢复本页默认
   - 恢复全部默认
   - 应用（如有延迟生效项）
   - 返回

### 8.3 选项控件规范

1. 开关项：用于布尔配置（如后台静音、离线收益）。
2. 滑杆项：用于连续值（音量、UI 缩放、震动强度），显示实时数值。
3. 下拉项：用于枚举值（显示模式、动态范围、难度模式）。
4. 步进器：用于离散数值（旧备份保留数量）。
5. 复合项：如“手柄震动（开关 + 强度）”采用主从结构，主项关闭时子项置灰。
6. 键位绑定项：进入“按键捕获态”，冲突时弹出替换/取消提示。

### 8.4 状态标记与反馈

1. 每个设置项显示状态标签：
   - 即时生效（绿色）
   - 需确认（橙色）
   - 需重启（蓝色）
2. 修改后显示“未保存变更”提示（仅针对非即时项）。
3. 应用成功使用轻提示（Toast），失败显示原因与可执行修复建议。
4. 离开页面时如存在未保存项，弹窗提示“保存/放弃/取消”。

### 8.5 视觉与风格建议（修仙农场向）

1. 整体风格：木纹 + 宣纸质感底板，低饱和自然色，强调宁静经营氛围。
2. 强调色分层：
   - 主强调：青玉色（可交互控件高亮）
   - 风险提示：琥珀色（需确认/危险项）
   - 错误提示：朱砂红（冲突/失败）
3. 字体层级：
   - 分类标题（大）
   - 选项名（中）
   - 功能描述（小，单行优先，超长折叠）
4. 焦点可视化：键盘/手柄聚焦时显示高对比描边与动效过渡（150ms-200ms）。

### 8.6 可用性与无障碍

1. 文本与背景对比度不低于 4.5:1。
2. 关键状态不只依赖颜色，辅以图标（✓、!、⟳）。
3. 支持纯键盘路径：Tab/Shift+Tab 导航，方向键调整滑杆。
4. 支持手柄路径：LB/RB 切分类，左摇杆移动焦点，A 确认，B 返回。
5. 字体放大后布局不重叠，描述自动换行，控件保持可点击区域。

### 8.7 页面行为细节

1. 分类切换保留滚动位置，返回分类后定位上次编辑项。
2. 恢复默认分两级：
   - 本页默认：仅重置当前分类
   - 全部默认：二次确认后执行
3. 危险项（覆盖云存档、清理缓存）必须二次确认并展示影响范围。
4. “需重启”项修改后集中展示在页底“待重启生效项”列表，避免遗漏。

### 8.8 玩家预期对齐（验收向）

1. 新玩家可快速找到基础三项：画面、音量、键位。
2. 进阶玩家可在 1 个页面内完成性能与辅助的精细调节。
3. 所有变更可回退，且不会误伤未涉及分类配置。
4. 设置结果在重启后与云同步后保持一致。
