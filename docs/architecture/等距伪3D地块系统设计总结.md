# 2D等距伪3D地块破坏系统设计与实现方案总结

## 1. 技术选型与参考案例

- 采用 Electron + JS 环境，推荐 Phaser.js（配合 isometric 插件）或 Pixi.js（需自写等距 tilemap 逻辑）实现2D等距伪3D地块破坏。
- 选型风险提示：Phaser 3 的等距能力主要依赖社区方案，落地前需先验证插件维护状态、示例可运行性、与当前 Phaser 版本兼容性。
- 参考案例：
  - 《星露谷物语》：等距 tilemap，地块有上表面和侧面，auto-tiling 过渡自然。
  - 《Terraria》：机制参考（融合/侵入规则），用于边缘侵蚀与污染扩散表现。
  - 《Minecraft》：机制参考（connected textures），用于连通纹理与边缘拼接策略。

## 2. 地块结构与贴图规范

- 每个地块网格为16×16像素。
- 视觉正方体分布：
  - 上表面（顶面）：16×8像素（菱形）
  - 左侧面：8×8像素
  - 右侧面：8×8像素
- 贴图命名建议：
  - `[地块类型]_[部位]_[过渡类型]_[方向]_[变体].png`
  - 示例：`grass_top.png`、`dirt_side_left.png`、`grass2dirt_transition_top.png`

## 3. Tilemap 数据结构

- 用二维数组 grid 存储地块，每个地块对象包含：
  - `type`：地块类型
  - `height`：高度
  - `variant`：贴图变体
  - `transitionMode`：过渡模式（auto-tiling、融合、硬边）
  - `meta`：附加属性

## 4. auto-tiling 算法说明

- 检查每个 tile 周围8方向地块类型，生成邻接码，查表选取合适贴图（中心、边缘、角落等）。
- 支持九宫格/十六宫格 auto-tiling。
- 若为融合模式，优先查找融合贴图，否则降级为普通边缘贴图。
- 高度差异时显示侧面。

## 4.1 auto-tiling 工程化约束（建议固定）

- 邻域定义：
  - 基础连接判定使用 4 邻域（N/E/S/W）
  - 角点修正使用 8 邻域（NE/SE/SW/NW）
- bitmask 约定（4 邻域）：
  - N=1, E=2, S=4, W=8
  - 邻接码范围 0-15，用于主贴图索引
- 角点补丁（可选）：
  - NE=1, SE=2, SW=4, NW=8
  - 用于角落缺口或内凹转角修正
- 优先级规则（从高到低）：
  - 脚本强制贴图 > 侵入/污染融合 > 普通 auto-tiling > 随机变体
- 冲突处理：
  - 同一帧出现双向侵入时，按地块层级优先级表决策（例如：corruption > grass > dirt）
  - 无明确胜者时，使用稳定排序键（tileTypeId）保证结果可复现

## 5. 侧面显示规则

- 若某一侧无同类型/同高度相邻地块，则显示该侧面。
- 边缘或高度差处显示对应侧面。
- 单独一个物块时，左右两侧面和上表面都要显示。

## 6. 地块过渡与融合

- 需支持三种过渡模式，按场景切换：
  - A：auto-tiling（自然和谐场景）
  - B：贴图侵入/融合（混乱、邪恶场景）
  - C：硬边无过渡（科技、秩序场景）
- 融合模式需美术支持多种过渡贴图。

## 7. Phaser.js 实现建议

- 使用 tilemap 管理地块，按等距投影公式渲染。
- 渲染前为每个 tile 计算邻接码，查表选贴图。
- 侧面贴图根据高度差和相邻地块类型决定是否绘制。
- 支持 run-time 切换过渡模式。
- 贴图资源按命名规范批量加载，渲染时自动拼接。
- 只在地块变化时重算贴图和重绘，提升性能。

## 8. 插件验收清单（立项前执行）

- 能在当前 Electron + Phaser 版本下正常运行最小示例。
- 支持等距坐标换算、输入拾取（tile picking）与相机滚动。
- 支持与自定义渲染层共存（顶面、侧面、特效层分离）。
- 最近维护记录可接受（版本更新、Issue 响应、文档完整度）。
- 若插件不满足要求，回退方案为 Pixi.js + 自研等距 tile 渲染管线。
