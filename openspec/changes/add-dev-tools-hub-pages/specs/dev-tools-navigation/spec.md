## ADDED Requirements

### Requirement: Home 页面提供开发工具入口

系统 MUST 在 `home` 页面提供“开发工具”入口按钮，用于进入开发工具聚合页。

#### Scenario: 从 Home 进入开发工具聚合页

- **GIVEN** 用户当前位于 `home` 页面
- **WHEN** 用户点击“开发工具”入口按钮
- **THEN** 系统跳转到开发工具聚合页

### Requirement: 开发工具聚合页展示工具入口并支持返回 Home

系统 MUST 提供独立的开发工具聚合页，集中展示所有开发工具入口按钮，并提供返回 `home` 的返回按钮。

#### Scenario: 开发工具聚合页返回 Home

- **GIVEN** 用户位于开发工具聚合页
- **WHEN** 用户点击返回按钮
- **THEN** 系统返回 `home` 页面

### Requirement: 工具占位页必须遵循上中下三段结构

系统 MUST 为每个开发工具入口提供空白占位页，并遵循固定三段式结构：

- 上区：工具名称 + 工具功能介绍
- 中区：空白占位区域（用于后续开发）
- 下区：`保存` 与 `后退` 按钮

#### Scenario: 进入工具占位页时显示三段结构

- **GIVEN** 用户位于开发工具聚合页
- **WHEN** 用户点击任一开发工具入口按钮
- **THEN** 系统进入对应工具占位页
- **AND** 占位页上区显示工具名称与功能介绍
- **AND** 占位页中区保留空白区域
- **AND** 占位页下区显示 `保存` 与 `后退` 按钮

### Requirement: 占位页后退必须返回开发工具聚合页

系统 MUST 在工具占位页支持“后退返回开发页”的固定导航行为。

#### Scenario: 从工具占位页后退

- **GIVEN** 用户位于任一工具占位页
- **WHEN** 用户点击 `后退` 按钮
- **THEN** 系统返回开发工具聚合页
