# 云笈仙田录

**Cloud Scripture: Tale of the Immortal Farm**  
简称：**CS: TIF**

《云笈仙田录》是一款 **2D 像素风 HD-2D 修仙田园题材游戏**。玩家将在云海之间开辟仙田、研习云笈、培育灵植，并在山野秘境与尘世传说之间，逐步走出一条属于自己的问道之路。

## 项目定位

- **游戏名称**：云笈仙田录
- **英文译名**：Cloud Scripture: Tale of the Immortal Farm
- **英文缩写**：CS: TIF
- **游戏类型**：2D 像素风 / HD-2D / 修仙 / 种田 / 叙事冒险

## 核心概念

游戏以“修仙”与“仙田经营”为核心，将东方幻想、山野田园和成长叙事结合在一起。玩家既要经营灵田、收集资源、炼制丹药，也要探索秘境、解读古老云笈，在人与天地、劳作与修行之间找到平衡。

## 美术与风格

- **视觉方向**：经典 2D 像素风结合 HD-2D 光影表现
- **氛围关键词**：空灵、古意、山野、仙气、静谧
- **体验目标**：在像素表现中呈现层次丰富的东方修仙世界

## 玩法方向

- 开垦与经营仙田
- 种植、培育与收获灵植
- 炼丹、制符与资源加工
- 探索山林洞府与秘境遗迹
- 推进角色修行与剧情成长

## 技术栈

### 核心引擎

| 依赖 | 版本 | 用途 |
|------|------|------|
| **noa-engine** | ^0.33.0 | 体素游戏引擎，用于无限大世界（Minecraft Classic 官方使用） |
| **@babylonjs/core** | ^6.40.0 | 3D 渲染引擎，noa 依赖 + 副本场景直接使用 |
| **simplex-noise** | ^4.0.1 | 程序化地形生成，生物群落温度/湿度映射 |
| **alea** | ^1.0.1 | 种子随机数生成器，确保世界生成一致性 |

### 桌面应用

| 依赖 | 版本 | 用途 |
|------|------|------|
| **electron** | ^28.1.0 | 桌面应用框架 |
| **electron-builder** | ^24.9.1 | 应用打包分发 |
| **electron-store** | ^8.1.0 | 本地存档数据管理 |

### 音频与构建

### 渲染特点

- **地形/建筑**：3D 体素风格（类 Minecraft）
- **植物/人物**：2D 纸片人精灵（Billboard）
- **大世界**：整个地球级无缝切换（noa-engine 区块流式加载）
- **副本场景**：洞穴、地下、秘境等使用场景切换模式
